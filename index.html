What I Do

Security Services

Focused on finding real, exploitable vulnerabilities — not checkbox compliance. I test the way attackers think.

Web App Penetration Testing
In-depth manual testing of web applications: authentication flows, business logic, session management, XSS, SQLi, CSRF, and more. Beyond automated scanners.
API Security Assessment
REST and mobile API testing: BOLA/IDOR, broken auth, mass assignment, endpoint enumeration, and WAF bypass techniques.
Auth & Access Control Testing
2FA bypass, OTP rate-limiting, token manipulation, path normalization bypass, privilege escalation, and SSO misconfiguration.
Infrastructure Exposure Review
Identifying exposed admin panels, Spring Boot Actuator leaks, hardcoded secrets in JS bundles, misconfigured cloud storage (S3/Azure), and monitoring dashboards.
Mobile & API Backend Testing
APK reverse engineering, hardcoded credential extraction, Firebase/Google API key exposure, and backend API testing from mobile app traffic.
Detailed Vulnerability Reporting
Clear, actionable reports with PoC, severity assessment (CVSS), business impact, and step-by-step remediation guidance your dev team can actually use.
